# FAQ-RAG: 智能问答系统（边缘端 + 个性化支持）

本项目基于 Retrieval-Augmented Generation（RAG）和传统 FAQ 结合构建，提供**高效、可部署在边缘端**的智能问答解决方案，支持用户级别的**个性化信息召回与回答生成**。

## 🌟 项目特点

### ✅ FAQ + RAG 双引擎
- **FAQ 匹配**：快速响应常见问题，低延迟、稳定。
- **RAG 检索生成**：当 FAQ 不命中时，使用基于向量检索 + LLM 生成的回答，更具扩展性和智能性。

### 🧠 个性化问答能力
- 支持为不同用户或设备加载个性化知识库（如用户偏好、历史提问、角色设定等），生成更贴近用户语境的回答。
- 可拓展接口支持用户画像更新与个性问答评估。

### 🚀 边缘端部署优化
- 支持轻量模型（如 deepseek，qwen）在边缘设备运行，脱离云端依赖。
- 本地向量数据库（如 mysql，maridb）可灵活嵌入，低资源占用。
- 保障数据隐私，尤其适用于教育、医疗、政务等对信息安全要求高的场景。
