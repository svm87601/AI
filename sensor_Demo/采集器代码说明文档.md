# 介绍文档

#### 程序文件夹路径：<u<u>>/home/pi4data_Demo</u>

## <u>程序文件是dataDemo.py</u>

## <u>配置文件是config.json</u>

### **1. 主要功能**

#### **(1) 传感器数据采集**

- 通过 **串口（Serial）** 读取连接的传感器（如土壤湿度传感器）数据。
- 使用 `read_sensor_data()` 方法读取数据，支持超时处理，避免阻塞。

#### **(2) 摄像头拍照**

- 通过 **Picamera2** 库控制树莓派摄像头拍摄照片。
- 图片自动保存为 `capture.jpg`，并转换为 **Base64 编码** 便于传输。

#### **(3) 数据存储**

- 将传感器数据和图片的 Base64 编码保存到 **`sensorData.js`** 文件（格式为 JavaScript 变量，方便网页直接调用）。
- 日志记录到 **`sensor_data.log`** 文件和控制台。

#### **(4) 云端传输**

- 通过 **MQTT 协议**（如 `paho.mqtt.client`）将数据发布到指定的 MQTT 服务器（如 `mqtt.iksns.net`）。
- 支持用户名/密码认证，确保传输安全。

#### **(5) 定时任务**

- 按配置的间隔时间（默认 30 秒）循环采集数据，支持动态调整。

### **2. 代码结构**

#### **核心类 `SensorDataCollector`**

- **初始化**：加载配置文件（`config.json`），建立串口、MQTT、摄像头连接。

- **数据采集**：
  - `read_sensor_data()`：读取串口传感器数据。
  - `capture_image()`：拍摄并编码图片。
  
- **数据发布**：
  
  - `save_to_js_file()`：保存到本地文件。
  - `publish_mqtt()`：推送至 MQTT 服务器。
  
- **资源管理**：自动清理串口、摄像头、MQTT 连接（`cleanup()`）
